## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><b>1. What internet speed do I need?</b></summary>
We recommend a minimum continuous download speed of <b>15 Mbps</b> for standard HD/FHD streams, and <b>30 Mbps</b> for high-bitrate 4K UHD channels. An Ethernet cable connection is always recommended over Wi-Fi.
</details>

<details>
<summary><b>2. Is a VPN required?</b></summary>
While our service works directly without a VPN, using one can help prevent your local Internet Service Provider (ISP) from throttling bandwidth during peak live sports hours.
</details>

<details>
<summary><b>3. What is the difference between M3U and Xtream Codes?</b></summary>
M3U loads a large, static text file of all channels at once, which can slow down devices with lower RAM (like older Firesticks). Xtream Codes connects through an API to load categories and guides on-demand, ensuring much faster navigation and automatic EPG updates.
</details>
